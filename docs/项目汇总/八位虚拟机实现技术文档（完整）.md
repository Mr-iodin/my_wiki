#                                                                                      八位虚拟机

### 一、八位指令集设计

​    计算机的指令集结构也称为指令系统。它代表着计算机的基本功能和使用属性，是计算机系统设计中的首要核心问题。

​     对于八位机的ALU，每一次原子操作只能处理八字节的指令或数据，而当使用计算机语言编写程序时，首先必须先将其翻译成机器指令代码，然后才能将其载入RAM中并执行。

* **运算指令**

本方案中所设计的有关ALU的汇编指令与机器指令的映射关系结构如下：                           

<img src="https://i.loli.net/2021/07/06/rUeRtqamWw7xXK9.png" style="zoom:50%;" />

​    在执行过程中，若指令寄存器中的第一位为 1，则表示这是一条 ALU 指令，接下来指令中的下三位将被发送到 ALU以告诉它需要做什么。后四位则用来表示本次运算所涉及到的数据，均采用寄存器寻址。

| Assembly language |       | Meaning                                    | Machine language |
| ----------------- | ----- | ------------------------------------------ | ---------------- |
| ADD               | RA,RB | 将 RA 与 RB 相加并讲结果放入 RB 中         | 1000 XX XX       |
| SHR               | RA,RB | 右移 RA 并将结果放入 RB 中                 | 1001 XX XX       |
| SHL               | RA,RB | 左移 RA 并将结果放入 RB 中                 | 1010 XX XX       |
| NOT               | RA,RB | 对 RA 进行非运行并将结果放入 RB 中         | 1011 XX XX       |
| AND               | RA,RB | 将 RA 与 RB 进行与运算并将结果放入 RB 中   | 1100 XX XX       |
| OR                | RA,RB | 将 RA 与 RB 进行或运算并将结果放入 RB 中   | 1101 XX XX       |
| XOR               | RA,RB | 将 RA 与 RB 进行异或运算并将结果放入 RB 中 | 1110 XX XX       |
| CMP               | RA,RB | 比较RA与RB 并更新对应的寄存器              | 1111 XX XX       |

* **加载存储指令**

​    同样，对于加载存储指令，该情况下，一个寄存器用于选择需要操作的RAM位置（即采用寄存器间接寻址），而另一个寄存器将用来存储需要存取的操作数（寄存器寻址），指令间的映射关系如下：

<img src="https://i.loli.net/2021/07/05/tDqB2zObJTQioLW.png" style="zoom:46%;" />

​    在这类指令执行过程中，若指令寄存器中的第三位为0，则表示这是一条加载存储指令，接下来的第四位用来标示是读数据还是写数据。

| Language |       | Meaning                        | Machine language |
| -------- | ----- | ------------------------------ | ---------------- |
| LD       | RA,RB | Load RB from RAM address in RA | 0000 XX XX       |
| ST       | RA,RB | Store RB to RAM address in RA  | 0001 XX XX       |

* **数据指令**

​    此类指令用于将一个字节从 RAM 加载到寄存器中，所以需要两个字节长，第一个字节是指令（op+需要操作的寄存器），下一个字节是一些将被放入寄存器的数据。

<img src="https://i.loli.net/2021/07/05/L28PSUNOtWrKwgi.png" style="zoom: 40%;" />

​    在这类指令第一个字节的前4位位操作码，倒数两位用于标示要操作的寄存器（寄存器寻址）；而第二个字节用于存放传入的操作数。

| Language |               | Meaning                   | Machine language     |
| -------- | ------------- | ------------------------- | -------------------- |
| DATA     | RB, xxxx xxxx | Load these 8 bits into RB | 0010 00 XX,XXXX XXXX |

* 跳转指令

​    跳转指令所做的只是改变IAR的内容，从而改变下一条指令和后续指令在RAM中的位置。它与数据指令相似，使用两个字节。它将IAR替换为紧跟在指令字节之后的RAM中的字节，从而改变下一条和后续指令在RAM中的位置，并且此指令中不使用位4、5、6和7：

<img src="https://i.loli.net/2021/07/06/yna1Qg89spjeuNI.png" style="zoom:45%;" />

到达第4位时，将IAR发送到MAR，而到达第5位时，会将选定的RAM字节移动到IAR。第六位和第七位便什么也不用做了。

| Language |      | Meaning                              | Machine language    |
| -------- | ---- | ------------------------------------ | ------------------- |
| JMP      | Addr | Jump to the address in the next byte | 0100 0000,XXXX XXXX |

还有一种跳转指令，是将Reg B的内容移动到IAR中。

<img src="https://i.loli.net/2021/07/06/pTxaQPdJ8ryIwvA.png" style="zoom:50%;" />

| Language |      | Meaning                   | Machine language |
| -------- | ---- | ------------------------- | ---------------- |
| JMPR     | RB   | Jump to the address in RB | 0011 00 XX       |

```c++
/* --------------2.列表的结构-------------- */
typedef struct List_ {
	int size;
	int (*compar)(const void * key1, const void * key2); // for sorting and searching

	ListElmt * tail;

/* ---------------3.公共接口--------------- */

 destroy 提供了一种用户定义的方法来在调用 list_destroy 时释放内存。 destroy 可以为 NULL。
 复杂度：O(1)

void list_destroy(List * list);
/*
 返回：无

 复杂度：O(n)
*/

int list_apply_elmt(List * list, ListElmt * element, 
					void(*fun)(ListElmt * l_element, void * args), void * fun_args);
/*
 返回： 0 成功，-1 失败
 描述：将 fun() 应用于元素； 如果元素为 NULL，则从头到尾应用 fun()。
 复杂度：O(1) 或 O(n)
*/

#define list_apply_all(list, fun, args) list_apply_elmt((list), NULL, (fun), (args))
/*
 返回： 0 成功，-1 失败
 描述：list_apply_elmt() 的宏； 将 fun() 应用于列表的所有元素。
 复杂度：O(n)
*/

int list_ins_next(List * list, ListElmt * element, const void * data);
/*
 返回： 0 成功，-1 失败
 描述：在列表中的元素之后插入一个元素。 如果元素为 NULL，则将新元素插入到列表的头部。
 新元素包含一个指向数据的指针，因此只要元素在列表中，内存就应该保持有效。
 这是由调用者完成的。
 复杂度：O(1)
*/

#define list_ins_first(list, data) list_ins_next((list), NULL, (data))
/*
 返回： 0 成功，-1 失败

 返回： 0 成功，-1 失败
 描述：从列表中删除元素之后的元素。 如果 element 为 NULL，则删除头部的元素。
 返回时，数据指向存储在被删除元素中的数据。 调用者管理内存。
 复杂度：O(1)
*/

#define list_rem_first(list, data) list_rem_next((list), NULL, (data))
/*
 返回： 0 成功，-1 失败
 描述：list_rem_next() 的宏； 删除列表的头部
 复杂度：O(1)
*/

#define list_is_head(list, element) ((element) == (list)->head ? 1 : 0)
/*
 int list_is_head(const ListElmt * element);

 复杂度：O(1)
*/

/*

int list_sort(List * list, int sort_up_down);
/*

 描述：链表排序功能（本例中为冒泡排序）。 1 排序，-1 排序。
 使用 LIST_SORT_UP 和 LIST_SORT_DOWN。
 复杂度：O(n*n)
*/

ListElmt * list_find_from(List * list, ListElmt * start, void * key);
/*
 返回：指向包含键的元素的指针，如果未找到或出错则为 NULL

 复杂度：O(n)
```

### 三、汇编器

##### 3.1 功能分析

​	从本质上讲，汇编器属于一种编译器，只是它和我们熟知的编译器的有略微的差别。

​	汇编器处理的“高级语言”是汇编语言，输出的是机器语言二进制形式。因此，对于汇编器的构造，实质上和编译器大同小异，也都需要进行**词法分析**、**语法分析**、**语义处理**、**符号表管理**和**代码生成**（机器代码）等阶段。

<img src="https://i.loli.net/2021/07/07/uIyb1EwMCF7lN6Z.png" style="zoom:40%;" />

​	从图中可以看出汇编器的设计中，在语法分析模块之前和前述编译器的结构完全相同，只是语法分析时要进行两遍的扫描过程，通过第一遍扫描获取文件定义的所有的段的信息以及全部的符号信息，第二遍扫描根据最新的段表和符号表，将所有的重定位信息收集到重定位表中，然后通过指令生成模块生成了代码段数据。

​	最后，从符号表中抽取有效数据定义形成数据段，符号导出到文件符号表段，再把所有的段按照elf文件的格式组装起来，形成最终的可重定位目标文件*.o。

### 四、反汇编器

##### 4.1 功能分析

​	反汇编器是一种工具程序，可以将机器代码转换为目标处理器专用的汇编代码或汇编指令。将机器代码转换为汇编代码的过程称为反汇编。就操作而言，反汇编就是汇编/交叉汇编的逆过程。

```c
// 将反汇编结果放入disasm_code并返回它的地址
char ** disasm_dis(byte * code, int size, int prefhex)
{
	static char dcode[ROWS][COLS];
	static char * disasm_code[ROWS] = {NULL};
	static char * hexpr[] = {"%s %02X", "%s %#02X"};
	
	if (prefhex < NO_PREF || prefhex > PREF_HEX)
	{
		fprintf(stderr, "Err: module disasm: Invalid value for argument ");
		fprintf(stderr, "prefhex in function disasm_dis()\n");
		exit(EXIT_FAILURE);
	}
	
	pref_nopref = hexpr[prefhex];
	
    // 标记显示模块的代码结束
	disasm_code[ROWS-4] = "--- --      -- --  --";
	disasm_code[ROWS-3] = "--- --      -- --  --";
	disasm_code[ROWS-2] = "--- --      -- --  --";
	disasm_code[ROWS-1] = "--- --      -- --  --";
	
	int i, ins_addr;
	for (i = 0; i < size;)
	{
   // 注意：在 diasm_get_instr() 中进行递增
		ins_addr = i;
		sprintf(dcode[ins_addr], "%02X> %s", ins_addr, diasm_get_instr(code, &i));
		disasm_code[ins_addr] = dcode[ins_addr];
	}
	return disasm_code;
}

//投影
static char * diasm_get_instr(byte * code, int * offset)
{
    /* 建立一个字符串助记符 */
	static char str_instr[COLS];
	
    // 获得更高的半字节
	int inst_code = code[*offset] >> INST_NBL;
    // 对于 reg a 和 reg b 来自低半字节
	int rega = 0, regb = 0;
	int flgs;
	
    // 以字符串形式获取指令代码
	switch (mcode[inst_code].size)
	{
		case 1:
			sprintf(str_instr, "%02X     ", code[*offset]);
			break;
		case 2:
			sprintf(str_instr, "%02X  %02X ", code[*offset], code[*offset+1]);
			break;
		default:
			break;
	}
	
    // 获取字符串中的指令助记符
	sprintf(str_instr, "%s %s", str_instr, mcode[inst_code].name);
	
	switch (inst_code)
	{
		case LOAD:
		case STORE:
		case ADD:
		case SHL:
		case SHR:
		case NOT:
		case AND:
		case OR:
		case XOR:
		case CMP:
            // 获取源 - dest 寄存器
			rega = code[*offset] & REG_A;
			regb = code[*offset] & REG_B;
            // 获取寄存器字符串
			sprintf(str_instr, "%s %s, %s", str_instr, gregs[rega >> 2], gregs[regb]);
			break;
		case DATA:
            // 获取目标寄存器
			regb = code[*offset] & REG_B;
			sprintf(str_instr, "%s %s,", str_instr, gregs[regb]);
            // 获取加载源
			get_next_byte();
			break;
		case JMP:
            // 获取跳转地址
			get_next_byte();
			break;
		case JMPR:
            // 获取目标寄存器
			regb = code[*offset] & REG_B;
			sprintf(str_instr, "%s %s", str_instr, gregs[regb]);
			break;
		case JCOND:
            // 获取标志
			flgs = code[*offset] & FLAGS_NBL;
			strcat(str_instr, flags[flgs & FLAG_C]);
			strcat(str_instr, flags[flgs & FLAG_A]);
			strcat(str_instr, flags[flgs & FLAG_E]);
			strcat(str_instr, flags[flgs & FLAG_Z]);
            // 获取跳转地址
			get_next_byte();
			break;
		default:
			break;
	}
	*offset += mcode[inst_code].size;
	return str_instr;
}
```

**指令具体实现：**

* ADD RA, RB

```c++
static void add(void)
{
	/* ADD RA, RB - adds the value in RA to the value in RB in RB
	 * modifies: CF, ZF
	 * step 0: get RA and RB
	 * step 1: add RA and RB in tmp
	 * step 2: add in the carry flag to tmp
	 * step 3: set the carry flag 
	 * step 4: move tmp to RB 
	 * step 5: set ZF */
	int ra = get_ra_ir();
	int rb = get_rb_ir();
	byte tmp = regs[ra] + regs[rb];
	
	tmp += regs[CF];
	regs[CF] = (regs[ra] + regs[rb]) > BYTE_MAX;
	regs[rb] = tmp;
	set_zf();
	return;
}
```

* SHR RA, RB

```c++
static void shr(void)
{
	/* SHR RA, RB - shifts RA one to the right into RB
	 * modifies: CF, ZF
	 * step 0: get RA and RB
	 * step 1: SHR RA in RB and | with CF << 7
	 * step 2: set CF  
	 * step 3: set ZF */
	int ra = get_ra_ir();
	int rb = get_rb_ir();
	unsigned int tmp = regs[ra];
	
	regs[rb] = (tmp >> 1) | (regs[CF] << 7);
	regs[CF] = ((tmp & 0x01) > 0);
	set_zf();
	return;
}

```

* SHL RA, RB

```c++
static void shl(void)
{
	/* SHL RA, RB - shifts RA one to the left into RB
	 * modifies: CF, ZF
	 * step 0: get RA and RB
	 * step 1: SHL RA in RB and | with CF
	 * step 2: set CF  
	 * step 3: set ZF */
	int ra = get_ra_ir();
	int rb = get_rb_ir();
	unsigned int tmp = regs[ra];

	regs[rb] = (tmp << 1) | regs[CF];
	regs[CF] = ( (tmp << 1) > BYTE_MAX );
	set_zf();
	return;
}
```

* NOT RA, RB

```c++
static void not(void)
{
	/* NOT RA, RB - sets RB to the reverse bits value of RA
	 * modifies: ZF
	 * step 0: get RA and RB 
	 * step 1: NOT RA in RB
	 * step 2: set ZF */
	int ra = get_ra_ir();
	int rb = get_rb_ir();
	
	regs[rb] = ~regs[ra];
	set_zf();
	return;
}
```

* CMP RA, RB

```c++
static void cmp(void)
{
	/* CMP RA, RB - compares RA and RB
	 * modifies: AF, EF
	 * step 0: get RA and RB 
	 * step 1: compare RA and RB
	 * step 2: set AF and EF */
	int ra = get_ra_ir();
	int rb = get_rb_ir();
	
	regs[AF] = regs[ra] > regs[rb];
	regs[EF] = regs[ra] == regs[rb];
	return; 
}
```

**加载存储指令：**

* LD RA, RB

```c++
static void load(void)
{
	/* LD RA, RB - loads RB from RAM address in RA
	 * 4. place RA in MAR 
	 * 5. place value at address in MAR in RB */
	regs[MAR] = regs[get_ra_ir()];
	regs[get_rb_ir()] = ram[regs[MAR]];
	return;
}
```

* ST RA, RB

```c++
static void store(void)
{
	/* ST RA, RB - stores RB to RAM address in RA 
	 * 4. place RA in MAR
	 * 5. place RB at address in MAR */
	 regs[MAR] = regs[get_ra_ir()];
	 ram[regs[MAR]] = regs[get_rb_ir()];
	 return;
}
```

**数据指令：**

* DATA RB

```c++
static void data(void)
{
	/* DATA RB - loads next byte as data in RB
	 * 4. send IAR to MAR
	 * 5. set the register to the value at MAR
	 * 6. add one to IAR */
	regs[MAR] = regs[IAR];
	regs[get_rb_ir()] = ram[regs[MAR]];
	++regs[IAR];
	return;
}
```

```c++
	 * 4. set IAR to RB */
```

```c++
static void jmp(void)
{
	/* JMP addr - jumps to the address in the next byte
	 * 4. send IAR to MAR
	 * 5. move value at address in MAR to IAR */
	regs[MAR] = regs[IAR];
	regs[IAR] = ram[regs[MAR]];
	return;
}
```

* J<flag(s)> addr

```c++
static void jcond(void)
{
	/* J<flag(s)> addr - jumps to the address in the next byte when
	 * any of the requested flag bits is set
	 * 4. move IAR to MAR
	 * 5. add one to IAR
	 * 6. move the address from RAM to IAR if any of the requested flags is set */
	 byte flags = 0;
	 
	 regs[MAR] = regs[IAR];
	 ++regs[IAR];
	 
	 flags |= (regs[CF] << 3) | (regs[AF] << 2) | (regs[EF] << 1) | regs[ZF];
	 
	 if (regs[IR] & flags)
		regs[IAR] = ram[regs[MAR]];
	 
	return;
}
```
